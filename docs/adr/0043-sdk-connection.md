# SDK 连接与重连

## 决定

SDK Core 编排宿主提供的 TLS、WSS 和可信会话。连接代次约束网络回调，账号存储世代
约束持久写入和鉴权切换。普通断连和网络切换重新拨号，沿用持久同步位点和同一设备。
会话撤销、踢出、主动退出先使旧回调失效，再提交账号世代推进。宿主负责取得新凭据。

提交会话目录后，SDK 从已发布目录核对当前订阅及补拉目标，沿用原 SQLite 补拉任务。
当前连接已完成 TLS/WSS 握手和订阅请求，且目录及关键消息位点已持久后发出 READY。
没有订阅目标时只需提交当前账号的目录。账号目录或当前会话为空也可以完成初始同步。

网络离线暂停重拨。普通失败使用有上界的指数抖动，稳定可用后重置计数。鉴权恢复沿用
现有会话发放与准入结果。连接与发送继续区分，符合原认证世代的持久 ACK 使用原关联
入口。服务器多端准入继续决定设备权限。

## 兼容

继续使用网关 v1 的单会话订阅和规范十进制字符串序号。旧 SQLite 004 和请求编码保持
兼容。目录目标通过既有消息补拉事务录入。
