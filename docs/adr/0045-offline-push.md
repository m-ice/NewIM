# 离线推送与设备在线状态

## 决定

继续使用发送事务中的 `im_outbox_events`。离线通知独立扇出、认领和重试，同一消息对同一
登录设备只安排一份通知。数据库保存目标和处理状态，供应商网络不参与发送事务或回执。
启用推送时从部署记录的起点收取新事件。关闭时保留可恢复的在途状态。

网关在有效订阅后记录租约，成功心跳续期。设备在线按账号、准入会话、设备和目标会话匹配，
同一设备订阅其他会话时仍可收到目标会话的离线通知。断开只释放对应连接的租约，进程异常
退出后租约到期。失效会话和过期租约均不参与判断。多网关读取相同的持久状态。

创建通知及开始供应商调用前核对成员权限、设备状态、当前租约、静音、已读和消息可见性。
撤回、移除或失去授权后取消尚未发送的通知。供应商已经接受的通知可能晚到，内容只用于
提醒打开应用，点击后由 SDK 根据当前登录态刷新目录与消息。通知不承载消息正文、账号信息
或授权凭据，收到通知也不直接写入消息或未读。

令牌登记绑定当前的准入设备。沿用 `im_push_tokens`，新增密钥标识、随机数和登记版本。
持久化密文使用服务侧密钥和设备、供应商、版本关联数据。旧密文行保留，设备再次登记后
进入新的投递流程。新登记与失效处理比较精确版本，迟到的供应商回执只处理发送时所用版本。

供应商适配器返回接受、暂时失败、永久配置失败或令牌失效等固定结果。APNs 根据 topic
和响应语义处理 410。FCM 依据结构化失效码处理注销。临时错误遵守供应商的等待指示并使用
有上限的退避。SDK 继续使用现有鉴权、目录、消息分页与本地事务。

## 验证

使用真实 PostgreSQL、两个认证设备与独立网关验证在线切换、重启、当前权限和待发取消。
供应商协议通过本地 TLS 端点验证，平台任务单独记录真实设备向供应商登记和接收的测试。
