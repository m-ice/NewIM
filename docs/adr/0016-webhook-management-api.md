# Webhook 管理 API

## 决定

部署操作者在 `newim-server` 的数字 IP 回环 API 管理 Webhook。设置 `NEWIM_WEBHOOK_MANAGEMENT_TOKEN_FILE` 时启用。文件须为进程所有者持有的绝对路径普通文件，沿用凭据文件读取和 Bearer 解析。管理凭据为 `whm_` 后接 64 位小写十六进制字符，启动后仅持有摘要。管理路由、投递 worker 和密钥封存使用同一数据库池与进程生命周期。启用时需完成 019 迁移。

HTTP 适配器仅负责受信鉴权、输入上界和状态码。目标、修订和投递操作由存储事务仲裁。扇出与会改变目标或待投递容量的操作共享原 advisory lock。目标最多 64 个处于启用状态。修改和软吊销使用正整数修订 CAS。URL 更新按旧绑定解封并按新绑定重封，密钥轮换追加修订。已排队的投递保留其冻结的目标和签名修订。

手动回放复用原投递行和 worker，适用于启用目标当前修订内符合条件的死信。每行最多手动入队一次，并复用全局、目标队列和原有单轮尝试上限。追加的运维审计同事务保存目标、修订、操作、请求 ID、时间及回放前的终态信息。相同回放请求 ID 与投递 ID 返回同一回执。操作没有对消息事务或消息事件做额外写入。

## 兼容与部署

默认关闭管理入口，已有 worker 可按原机理工作。部署可通过撤去凭据文件配置关闭 API。019 追加审计和查询索引，保留原目标、投递、outbox 和签名契约。运维回环入口直接供可信部署进程使用，认证凭据与普通用户和发牌服务独立。
