# 0025 · 鉴权实时消息网关

## 接入

新增独立的 `newim-gateway` 进程，直接监听 TLS 1.2 及以上版本的 HTTP/1.1。部署时先应用数据库迁移 009，并为 HTTP 服务和网关同时启用设备准入。网关复用既有 Bearer 核验，从数据库读取用户、设备、会话和令牌的绑定，独立生成连接标识。第一个版本接入可设置 Authorization 的原生客户端。

握手和订阅协议见 [实时消息网关](../../specs/gateway/websocket.md)。连接、订阅与数据库工作均有时限。网关按直接连接地址及经核验的用户和设备限制握手，每个进程另设连接上限。已通过令牌校验的握手将 RFC 6455 随机值的 SHA-256 摘要和令牌标识一起提交至数据库。唯一约束覆盖同一令牌的并发握手和跨进程重放，过期记录按批清理。客户端重连应由 WebSocket 库生成新随机值。

## 投递与恢复

每条连接订阅一个会话。网关用当前会话成员身份读取 PostgreSQL 中已提交的消息，沿用消息帧和会话序号。单写者每次读取有限的一页，按顺序写出。客户端持久化消息后记录序号，重连携带这个序号。连接中断发生在落盘与游标持久化之间时，客户端以会话序号和消息标识合并重复项。

数据库身份守卫由鉴权、增量读取和握手存储共用。连接在读取和投递前复查令牌和会话，在心跳时继续核验。首次通过成员校验的订阅和成功收到的 Pong 更新设备最近活跃时间；更新在账号锁内复查会话和令牌，与超限淘汰串行。发现设备淘汰时读取与会话绑定的已提交撤销事件。已通过投递前复查的批次可能先于撤销通知完成，后续复查会阻止下一批次。收到停止信号后关闭监听并为现有连接发送排空通知。达到排空总时限后关闭剩余套接字。检测到数据库身份永久变更时退出，由部署方重启并重新核验数据库。
