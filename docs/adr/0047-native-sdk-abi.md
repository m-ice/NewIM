# 原生 SDK 共享 C ABI

状态为候选。ABI 实现、C 调用和端到端验收随原生桥一并发布。

## 边界

在现有 Rust SDK Core、协议和 SQLite 适配器之外提供一个可静态链接的 C 接口。
Swift、JNI、Dart FFI 和其他原生宿主通过同一个头文件连接。宿主在串行 SDK 工作线程
提交生命周期与传输事件，并提取执行所需的网络和定时动作。平台负责凭据保管、系统
权限、TLS 验证和连接调度。

当前账号的连接状态、同步位点、未读、发件队列、消息去重和持久回执继续由 Rust SDK
与 SQLite 维护。连接失败、退出、通知点击与重连沿用既有代次和恢复规则。宿主按当前
会话和网络动作标识提交完成，原生桥在进入 SDK 和存储前核对所属账号、连接及操作。

## 进程内接口

C 接口使用定宽状态码、进程内句柄和调用者提供的缓冲区。输入在调用返回前完成读取
或复制。输出提取使用容量与实际长度，缓冲不足时保留队首。关闭使句柄及其未交付
动作失效，重新打开分配新句柄。Rust panic 在 ABI 边界转为固定错误，诊断使用固定码。

桥内消息是本地宿主接口，服务端继续使用既有 TLS HTTP、WSS 和同步格式。平台 API
与打包按各自目标验证。桥的验收由实际 C 链接、原生 SQLite、已验证 TLS 和当前 SDK
回归组成。
