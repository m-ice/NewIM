# 0031 · 会话投影源接线与回填

私聊或群的首次创建、新消息、加入、重入、退出、移除与解散在源事务中记录会话修订。新账号在预配事务中创建就绪的空投影。沿用账号修订、目录、tombstone 和签名游标。接线统一使用 `NEWIM_CONVERSATION_PROJECTION=1`，各进程在启用时验证迁移 014。

写入顺序为成员表、会话、按 ID 排序的投影账号行。在原事务内批量更新所有受影响账号，源与投影一起提交或回滚。遇到相同摘要沿用既有修订。移除记录以曾可见的投影为前提。受历史边界限制的成员尚无可见消息时保存零摘要序号和空指针。以后达到该成员的消息窗口时，使用其最新可见的序号和指针。读取消费到历史权限已收紧的旧摘要时退回重建游标。

迁移 014 在投影账号保存 `source_ready` 和 `source_after_key`。存量账号保持未就绪。独立回填命令按账号处理，将当前成员与旧投影键按会话 ID 合并分批。批次按顺序锁住会话，再锁账号和核对原代际及进度。重新判断成员授权后写最新摘要或移除记录。进度、投影和最后一批的就绪状态共同提交。

上线先应用迁移，升级并排空旧写进程，再验证各源入口均启用事务投影，然后执行回填。后续公共读入口要求账号就绪。若回退旧写进程，先停止对外读并重置账号就绪状态、推进代际、清除回填位置。重建沿用已有投影数据，按相同合并目录重新核对。
