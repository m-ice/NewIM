# 0024 多端设备准入

Task: NIM-SRV-001

可信应用使用现有签发凭证为已登记账号准入设备。应用提交经核验的设备标识和平台，活跃时间取服务器时间。在同一个 PostgreSQL 事务中写入会话、令牌摘要以及超限撤销。提交后才返回明文令牌。

## 设备与配额

同账号的已准入、尚未撤销的会话按设备去重。会话持续占用配额直到撤销，令牌过期仍受令牌有效期约束。再次准入同一设备时沿用未撤销的已准入会话并签发新令牌。已登记设备的平台保持稳定。

默认每账号 8 台设备，同平台 3 台。准入先收敛各平台上限，再检查账号上限。部署调低上限后，在该账号下一次准入时执行相同规则。两次均按最近可验证活动时间升序，等值时按设备标识字节顺序。保留申请准入的设备。单设备模式使账号上限为 1。

最近活动由已验证的准入和签发写入，可由后续网关接入已核验活动。迁移 008 保存可信平台、最近活动和会话准入时间。升级后保留原令牌和会话。启用前用可信平台来源和已有签发时间完成存量核验与登记。已撤销的会话继续保持撤销，未登记的平台和活动时间保留为空，待核验后登记。若存在仍可鉴权的未登记会话或已登记会话缺少可信设备记录，启用时拒绝启动。

## 事务和重试

同一账号的准入和启用状态下的旧签发入口共用账号行锁。会话、令牌按稳定顺序更新。被淘汰设备的未撤销会话与令牌在同一事务中失效，每条本次撤销的会话生成一条持久事件。撤销事件按账号重读，游标范围为该账号，排序键为事件 ID。

旧签发入口在启用准入后仅为已准入且仍有效的会话签发。提交失败返回稳定错误。提交结果不确定时返回失败且省略令牌；仍可准入的同设备重试可获得新的令牌。数据库存储令牌摘要。

## 启用

`NEWIM_AUTH_DEVICE_ADMISSION=1` 与既有可信应用签发入口一同启用。配置 `NEWIM_AUTH_MAX_DEVICES` 和 `NEWIM_AUTH_MAX_DEVICES_PER_PLATFORM` 可调整上限。`NEWIM_AUTH_SINGLE_DEVICE=1` 启用单设备模式。共享数据库的写入进程按统一配置切换，切换前排空旧写入进程。
