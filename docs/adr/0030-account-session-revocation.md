# 0030 · 账号级会话撤销

可信应用核验改密、退出全部设备或封禁动作之后，调用已启用的回环接口 `POST /api/v1/internal/session/revoke-account`。入口要求应用发行凭证，绑定到已启用的设备准入运行时。请求提供 `userId`、稳定的 `requestId` 和原因 `password_changed`、`signed_out_all` 或 `account_blocked`。可信应用负责凭证更新和封禁判断。

仓储沿用设备准入的账号行锁，再按 ID 锁定该账号的全部未撤销会话和相关令牌，包括遗留会话及已过期令牌。会话和令牌的撤销、每个会话的原因事件及动作回执在一个事务提交。撤销时间满足记录的创建时间约束，既有撤销时间和事件保持原值。

迁移 013 扩展现有会话撤销事件的原因约束，保留原设备淘汰原因。回执以账号和请求标识为键，保存原因和原会话数量。无会话时也保存回执。同一动作重试返回原数量。重复键对应不同原因时返回 `AUTH_REVOCATION_CONFLICT`。撤销后来准入的会话使用新的请求标识。

客户端重新鉴权时，已撤销的令牌立即失效。已建立的 WSS 连接通过现有会话复核接收 `1008 session_revoked`，设备淘汰继续使用 `device_limit`。部署依次应用 013、升级回环服务、打开 `NEWIM_AUTH_ACCOUNT_REVOCATION=1`。回退时关闭开关再回退二进制，数据库保留迁移、事件及回执。
