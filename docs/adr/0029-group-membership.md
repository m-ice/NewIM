# 0029 · 小群成员权限与历史

小群沿用群会话标识、持久化发送和 WSS 消息序列。群主可管理管理员、转让和解散。群主与管理员审批申请。入群模式 0 要求申请审批、邀请直接入群，模式 1 增加对普通成员邀请的审批，模式 2 允许申请和邀请直接入群。转让后旧群主取得接任者此前的角色。

迁移 012 为成员记录增加加入后的历史起点、离开时间和结束序号。已读记录与媒体引用仍指向原成员行。发送、群管理和新媒体凭证检查当前成员。同一群的角色、退出和消息写入在会话锁下排序。群体禁言约束普通成员，个人禁言也可约束管理员。有效成员可重放禁言前已提交的同意图回执。

默认允许新成员读历史。关闭后，加入在同一事务记录现有消息尾序号，从下一序号起读。重入清空结束上限，保留已有历史起点或依当前策略提高它。退群、移除和解散为有关成员保存当时的已提交序号。当前成员的结束序号为空，结束序号 0 表示从未收到可见消息。

消息读取先核对会话实际持久化指针，再在同一读取快照中应用成员范围。授权起点可以早于或晚于客户端游标，读取从两者中的较大值继续。返回的尾序号以授权上限为界；可见范围内依旧要求连续。旧结构通过核验后使用原查询，结构或查询异常失败关闭。

群资料和成员生命周期变更与账号修订同事务提交。成员从自己的修订继续同步，离开时取得自己的移除事件。部署先应用 012，升级读写进程，再启用群变更和公开群发送。
