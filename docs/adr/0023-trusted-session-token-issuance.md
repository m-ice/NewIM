# 0023 可信应用为现有会话签发令牌

Task: NIM-SRV-009

应用后端完成账号鉴权后，通过受保护的回环入口为已登记的会话签发 IM 令牌。已有会话服务在原事务中验证用户、设备、会话、撤销状态和 TTL，只保存摘要。事务提交成功后，调用方收到明文令牌。

## 配置与边界

`NEWIM_AUTH_ISSUER_TOKEN_FILE` 指向服务账号拥有、权限为 0400 或 0600 的绝对路径。文件为 32 个随机字节的 64 位小写十六进制编码，可带一个换行。启动时核对文件类型、所有者、权限和长度，在内存保留凭证摘要。macOS 的凭证文件须清除扩展 ACL。更换凭证后重启服务。

`NEWIM_AUTH_ISSUER_TTL_SECONDS` 为 1 至 86400 的整数。两项均缺省时签发入口关闭。一旦配置任一项，启动时校验全部签发配置、回环监听和现有会话存储。错误使用固定的 `SERVER_INVALID_AUTH_CONFIG`。

应用凭证用于签发入口的单值 Bearer Authorization。验证通过后，只读取应用提交的会话绑定。签发凭证与用户令牌采用独立验证边界。HTTP 响应禁用缓存，日志省略凭证、明文令牌和摘要。签发接口使用现有会话和设备记录；新设备准入、额度与网关归 NIM-SRV-001。

## 验收

使用固定 PostgreSQL 和真实回环 HTTP 验证签发、用新令牌查会话、撤销后失效、应用凭证隔离、跨用户绑定拒绝和持久层故障时的失败响应。保持数据库迁移和已验收的查询、登出、私聊入口行为。
