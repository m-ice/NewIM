# 0035 · S3 兼容媒体存储

沿用媒体 HTTP 入口和就绪事务。网关显式选用 S3 时，应用继续使用现有对象写入、验证读取接口。S3 调用由 AWS SDK Go v2 签名。部署指定私有桶、区域和可选自托管 HTTPS 地址，网关核对实际端点、证书和主机名。默认部署使用本地文件。

上传先在私有临时文件核对长度和 SHA-256，再执行带校验和的条件 PUT。发生重放时读取现有对象并校验大小和内容。下载使用一次完整 GET 验证文件，在响应前由应用复核访问权限。每个传输最多占有一个 100 MiB 的临时文件，关闭时释放。按每个网关的传输并发上限约束临时目录占用。

同一媒体库的网关选用同一个持久对象后端。切换和回退前先排空媒体写入，复制并校验最终对象集，然后一起切换网关并恢复写入。媒体库继续使用已有迁移。服务门禁固定对象服务镜像，验证网关、PostgreSQL 与 S3 之间的真实 TLS、对象校验和重启恢复。
