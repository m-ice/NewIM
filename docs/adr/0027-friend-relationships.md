# 0027 · 好友申请和关系同步

TLS 网关以会话身份处理好友申请、响应、列表、备注和删除。好友记录按所属账号分别存储。接受申请时补齐双方的好友记录，同时完成反向待处理申请。删除移除执行者自己的记录。已存在的好友记录保留原备注，备注的写入和事件仅属于执行者。

迁移 011 保存好友记录、申请、账号修订及变更。变更复用私聊的账号对锁，再按账号标识顺序锁定受影响的修订行。更新关系和写入变更在同一事务提交。现有黑名单继续按方向约束私聊，好友列表支持按当前账号的黑名单过滤。

账号修订在账号锁内递增。同一账号的关系变更按修订顺序读取。客户端先读取未过滤的列表和申请，再从首个列表响应的修订补拉变更，去重后保存新的游标。每页使用一个已提交的读取快照。好友资料沿用现有公开字段。黑名单筛选根据查询时的黑名单状态计算。
