# 0026 · 用户预配与资料

可信应用使用现有回环凭证预配账号。预配在同一事务写入账号和初始资料，并发重复请求返回原账号的当前资料。客户端通过 TLS 网关以现有会话令牌读取公开资料和更新自己的资料。

迁移 010 增加以 `im_users.user_id` 为外键的 `im_user_profiles`。已有账号可直接读出空资料。首次资料修改时建立记录，后续写入仅更新发送的字段。资料和账号继续使用原来的用户标识。资料库连接与同一进程的鉴权、消息存储共用 PostgreSQL 身份守卫。

`NEWIM_USER_PROFILE=1` 分别启用回环预配入口和 TLS 资料接口。回环进程要求配置已有可信应用凭证。TLS 网关使用已核验账号和直接连接地址，独立于 WebSocket 握手预算。头像地址作为展示字段存取，头像上传、联系人备注、群内昵称分别走已有模块边界。
