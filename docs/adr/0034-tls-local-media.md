# 0034 · TLS 本地媒体链路

TLS 网关沿用当前会话身份和现有媒体凭证。客户端先从 `/api/v1/media/uploads/grant` 取得短期凭证，再向 `/api/v1/media/uploads/complete` 上传内容。对象以 100 MiB 为上限，在收到完整数据并验证大小及 SHA-256 后提交就绪元数据。待提交凭证在行锁内校验时效和当前会话、令牌及成员权限。已就绪的同内容重试重新核验权限后返回原元数据。

网关按路由设置有限的流式期限，数据库调用继续使用短期限。私有下载先取得资产和会话授权，经同一文件描述符核验对象后再次核验权限，发送附件字节。文件路径由服务端分配，响应类型固定为 `application/octet-stream`。文件、凭据和目录路径不进入诊断。

媒体开关为 `NEWIM_MEDIA_HTTP=1`，对象目录由 `NEWIM_MEDIA_LOCAL_ROOT` 明确配置。网关启动时核对媒体元数据字段，媒体池与网关共享数据库身份保护。多个媒体网关使用同一个私有持久对象目录。启用时 TLS 发送从原入口写入媒体 v1，并沿用已提交回执、WSS 和消息序号。`NEWIM_CONVERSATION_SYNC=1` 提供媒体消息补拉。回退关闭媒体入口，持久数据继续保存。
