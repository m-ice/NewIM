# 0036 · 会话已读位点

同账号的设备共享 `im_read_states` 中每个会话的已读位点。TLS 网关在 `/api/v1/conversations/{conversationId}/read` 读取或推进当前账号的位点，响应包含授权历史起点、会话尾序号及最后实际更新时间。已过期身份、非成员和离群成员按各自稳定错误退出。

推进使用条件 UPSERT。相同或较旧请求读取当前位点。有效位点以上次持久位置和历史起点的较大值计算，任何位置都须在持久会话尾序号内。事务复用会话与令牌的锁定和设备准入，随后锁定会话及当前成员，于提交前复查令牌时间。迁移 015 增加可空时间字段，旧行按原值读取。

启用 `NEWIM_READ_WATERMARK_HTTP=1` 的网关启动时校验所需迁移。关闭入口后数据库继续保存位点与更新时间。
