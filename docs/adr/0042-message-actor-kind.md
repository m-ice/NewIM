# 机器人账号与消息身份

## 决定

在已有回环可信预配入口增加可选 `actorType`。部署启用分类预配后可为新账号指定
`HUMAN`、`BOT`、`SYSTEM` 或 `AI_AGENT`。普通账号及历史账号默认为 `HUMAN`。
其他三类随首次账号预配在同一事务写入关联表，账号重试维持原分类。设备、会话和
成员权限继续使用相同的持久授权路径。

发送者分类由服务端从已验证的发送者 ID 读取。ACK、WSS、消息补拉和签名 Webhook
对非人类发布者带可选 `senderType`。旧人类消息的编码继续沿用。现有协议版本和
消息动作沿用持久写入、原 ACK 重试和原投递身份规则。

## 部署

迁移 020 追加分类表。完成迁移并更新所有依赖分类的发送、读取和投递进程后，再
启用可信分类预配。关闭预配保留新进程的持久分类读取。回退旧进程前暂停关联的
发送、读取和投递，在恢复新版后重新开放。
