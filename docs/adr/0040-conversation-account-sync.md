# 0040 · 会话设置与客户端同步

会话设置、个人清空下界及删除状态按账号与会话保存。临界区沿用现有成员、会话和账号修订锁序，将个人变更及不可变修订同时提交。个人历史下界过滤目录摘要、消息补拉和发送者查询回执的目标消息。权威已读位点继续依据成员历史边界。删除后的会话在当前成员收到新持久消息时恢复可见，已有设置版本继续单调。

迁移 018 同时保存个人设置和修订快照。已升级的服务端无论是否开放设置接口，都执行已持久化的个人历史状态。新的公开设置字段随开关启用。关闭入口时保留历史约束与旧接口格式。

客户端使用同一 SQLite 数据库中的独立会话目录与游标状态。时间戳不参与合并，服务端修订和本地轮次共同确定请求顺序。一个本地写事务提交整页。游标过期时重新引导，终页原子发布目录和检查点。已有收据、消息和待发队列继续沿用原存储事务。
