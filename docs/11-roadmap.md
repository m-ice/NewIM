# Roadmap

## Phase 0 — Foundation
Repo, ADRs, toolchain, protocol skeleton, CI, licensing/provenance rules.

## Phase 1 — Reliable 1v1 core
Auth/session, private conversation, text messages, persistence ACK, sequence, sync, local store/outbox.

## Phase 2 — Product essentials
Image/audio/gift/system messages, read/unread, recall, block, stranger policy, push, media.

## Phase 3 — Commercial hardening
Observability, chaos/fault injection, backup restore, real-device lifecycle matrix, performance baselines, rolling upgrades.

## Phase 4 — Platform breadth
Flutter/native/uni-app/desktop/web production packaging and compatibility matrix.

## Later
Small groups, then larger group/channel models only after explicit product scope and load evidence.
