# External source boundary

Use public vendor docs/repositories/issues/PRs to learn capabilities, failure modes and API semantics. Do not present inferred internals as vendor facts.

OpenIM is the preferred open reference when additional implementation research is necessary, but license boundaries still apply. In particular, do not copy AGPL client SDK/demo code into NewIM Core. Third-party commercial SDKs may be compared at documented behavior/API level only unless their licenses explicitly permit code reuse.

Any external code reuse needs a provenance record under `third_party/provenance/` before merge.
