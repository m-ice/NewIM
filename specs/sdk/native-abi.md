# 原生 SDK C ABI

共享入口见 [newim_native.h](../../sdk/native/include/newim_native.h)。宿主先核对
`newim_native_abi_version()`，在自己的串行 SDK 工作线程调用同一账号实例。
路径与账号为 UTF-8 字节序列。路径指向宿主配置的账号存储根目录。输入缓冲区和输出
缓冲区在调用期间由宿主持有，SDK 按长度读取或写入。每次事件输入和输出最多 1 MiB。

| 入口 | 契约 |
| --- | --- |
| `newim_native_open` | 打开指定账号存储并返回非零句柄。为新句柄绑定已打开的存储实例和当前世代。 |
| `newim_native_submit` | 处理一条有界的 UTF-8 事件。完成信息必须引用原网络动作。返回忙时，事件尚未执行，宿主可先提取已有动作。 |
| `newim_native_next` | 按序取出一个动作或通知。容量不足时返回所需字节数并保留队首。空缓冲和零容量可查询大小。无待取事件时长度写为零。 |
| `newim_native_close` | 释放账号实例与队列，工作线程停止向旧句柄交付完成。旧句柄后续返回已关闭。 |

宿主将已验证 TLS 连接上的响应关联到发起它的操作，再交回原生桥。桥使用既有协议解码器和
SDK 状态机核对回执、顺序和存储提交，再发布对应动作。账号切换打开另一存储实例。旧实例的
网络完成无法推进新实例的目录、发件队列或 UI 事件。

状态码和所有权属于 ABI v1。原生桥完成后，以实际 C 调用核对输入边界、缓冲不足、关闭、
发件、持久回执、断线补拉和通知点击。
