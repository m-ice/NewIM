# SDK 连接与重连

宿主给每个本地账号实例持有一个 `Connection`，提供可信会话、TLS/WSS、时钟和随机源。
凭据与真实登录设备绑定，宿主核实账号和设备后返回有效期。普通重连复用该设备的有效凭据。
宿主在同一队列串行处理连接事件和存储结果，并给握手、请求和写入设置超时。

每次连接尝试分配新的连接代次。宿主通过 `accepts` 检查回调票据后才应用网络结果。
取消后释放对应传输并丢弃旧连接的目录、补拉和实时回调。进程内重建时把上一个连接代次
交给新协调器。待发 ACK 继续使用原来的认证世代、原始请求和持久关联检查。

在线后从 TLS 提交会话目录终页，再读取已发布目录及当前会话位点。同一读版本的快照组成
`CommittedDirectory`。网关用 `newim.v1`，每条 WSS 连接订阅一个会话，首帧的
`afterSeq` 为本地已持久的实收位点与历史下界的较大值。握手及首帧写入完成后，如果
该位点落后于本轮已发布的会话尾部，宿主把目标交给原 SQLite 补拉任务。宿主在事务提交后
读取进度，协调器确认达到目标后发出 READY。已追平的会话和空会话在首帧写入后可用，
没有订阅目标的账号在目录提交后可用。实时消息仍由原消息同步路径处理。

网络离线暂停拨号，恢复时继续原退避期限。换网和暂时故障使用 0.5 至 1 倍的有界指数退避，
初始窗口 1 秒，上限 5 分钟。连续可用 30 秒重置窗口。会话权限变化触发目录重读，
订阅协议错误暂停连接，修正后由宿主恢复。

过期、撤销、设备被踢和主动退出取消当前连接并落盘推进存储世代。宿主先确认提交结果，
再交回新世代。提交结果不确定时重开 SQLite 并核对世代。若仍是旧世代则重试原请求，
若已推进则交回已确认的新世代。存储世代耗尽时取消连接并报告存储错误。
自动鉴权恢复保留原因并按正常发牌流程重新登录。主动退出在世代提交后关闭，等待显式恢复。
登录成功后宿主可以恢复当前世代的补拉和待发任务。其他设备独立执行服务端准入和同步。

`make sdk-connection-check` 覆盖状态、退避、网关编码和目录补拉持久性。
`make sdk-connection-integration` 使用真实 PostgreSQL、TLS、WSS 和锁定版本的 SQLite。
