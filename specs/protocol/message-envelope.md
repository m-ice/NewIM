# Message envelope v1 draft

```json
{
  "clientMsgId": "01...",
  "serverMsgId": "01...",
  "conversationId": "c_...",
  "conversationSeq": 1088,
  "senderId": "u_...",
  "type": "text",
  "version": 1,
  "payload": {},
  "serverTime": 0
}
```

This is a draft contract. Field encoding, maximum sizes and canonical ID formats require ADR approval before production code depends on them.
